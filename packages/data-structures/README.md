# Data Structures

Este directorio contiene implementaciones de estructuras de datos en TypeScript.

Cada estructura debe incluir:

- `src/` con implementacion
- `tests/` con pruebas unitarias
- `README.md` propio con objetivo, API y complejidad

Estructuras planificadas:

- stack
- queue
- linked-list
- tree
- graph
- heap
- trie
