# Deep Types

Implementacion de tipos recursivos para modelar estructuras anidadas en TypeScript.

## Objetivo

Practicar transformaciones profundas sobre objetos:

- `DeepReadonly<T>`
- `DeepPartial<T>`

## Estructura

```text
deep-types/
  src/
    deep-readonly.ts
    deep-partial.ts
    index.ts
  tests/
    deep-types.test.ts
```

## Nota de entrevista

Estos tipos son clave para demostrar dominio de:

- conditional types
- mapped types recursivos
- manejo de casos base (primitivos y funciones)

Referencia recomendada de base conceptual:
`packages/types/fundamentals/README.md`
