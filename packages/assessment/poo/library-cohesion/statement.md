# Ejercicio: Cohesion en Library System

Modelar una clase `LibraryAccount` con responsabilidades de prestamo.

## Requisitos

- Debe permitir prestar y devolver libros.
- Debe exponer lectura de libros prestados.
- No debe incluir responsabilidades ajenas (marketing, facturacion externa, etc.).

## Pregunta academica

Indicar por que `sendMarketingEmail()` no pertenece a la clase.
