# Pseudocodigo de razonamiento (ES)

1. Detectar simplificacion peligrosa: "compila" no equivale a "buen diseno".
2. Separar niveles de calidad:
   - Correccion sintactica/funcional minima.
   - Calidad de diseno (cohesion, acoplamiento, extensibilidad).
3. Verificar si una clase mezcla responsabilidades.
4. Concluir: compilacion y tests minimos no garantizan calidad de diseno.
