# Ejercicio: Balanced Parentheses

Dado un string con caracteres `()[]{}`, determinar si esta balanceado.

## Entrada

- `input: string`

## Salida

- `boolean` (`true` si esta balanceado, `false` en caso contrario).

## Ejemplo

- `"([]{})"` -> `true`
- `"([)]"` -> `false`

## Restricciones

- Resolver con stack.
- Explicar por que no alcanza con contar cantidad de parentesis.
