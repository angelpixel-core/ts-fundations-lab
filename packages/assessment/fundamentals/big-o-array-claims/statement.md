# Ejercicio: Big O sobre Arrays (Afirmaciones)

Evaluar cada afirmacion como Verdadero/Falso y justificar en una frase:

1. "Acceder por indice en un array es O(1)".
2. "Insertar al inicio de un array siempre es O(1)".
3. "Recorrer un array completo es O(n)".
4. "Eliminar al final de un array es O(n)".

## Objetivo

Practicar precision academica y detectar absolutos incorrectos.
