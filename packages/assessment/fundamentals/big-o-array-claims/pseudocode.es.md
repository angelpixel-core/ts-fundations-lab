# Pseudocodigo de razonamiento (ES)

Para cada afirmacion:

1. Identificar operacion exacta (acceso, insercion, borrado, recorrido).
2. Determinar si requiere corrimientos de elementos.
3. Revisar si la frase usa absolutos ("siempre", "nunca").
4. Clasificar Verdadero/Falso segun comportamiento estandar de arrays.

## Idea clave

En arrays, la diferencia central es si hay o no corrimiento de posiciones.
