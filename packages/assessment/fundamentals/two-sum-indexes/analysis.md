# Analisis

## Complejidad

- Tiempo: O(n).
- Espacio: O(n) por el diccionario auxiliar.

## Trampas comunes

- Resolver con loops anidados (O(n^2)).
- Guardar primero y comparar despues, devolviendo el mismo indice dos veces.

## Traduccion academica

Se utiliza hash map para convertir un problema de pares en busqueda de complemento.
