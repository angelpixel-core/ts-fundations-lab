# Analisis

## Complejidad

- Tiempo: O(n).
- Espacio: O(n) por el nuevo string resultante.

## Trampas comunes

- Usar helper prohibido por restriccion (`split/reverse/join`).
- No contemplar string vacio.

## Traduccion academica

La inversion se resuelve con recorrido inverso y acumulacion secuencial.
