# Ejercicio: Reverse String

Dado un string, devolver otro string con los caracteres en orden inverso.

## Entrada

- `text: string`

## Salida

- `string`

## Ejemplo

- Entrada: `"hola"` -> `"aloh"`

## Restricciones

- Implementar sin usar `split("").reverse().join("")`.
- Explicar complejidad temporal y espacial.
