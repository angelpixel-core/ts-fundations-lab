# Pseudocodigo (ES)

1. Crear un conjunto vacio llamado `seen`.
2. Recorrer cada `number` del arreglo.
3. Si `number` ya existe en `seen`, devolver `true`.
4. Si no existe, agregarlo a `seen`.
5. Si termina el recorrido, devolver `false`.

## Idea clave

El set permite validar existencia en tiempo constante promedio por elemento.
