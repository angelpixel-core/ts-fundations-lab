# Ejercicio: Duplicates Detector

Dado un arreglo de numeros enteros, determinar si existe al menos un duplicado.

## Entrada

- `numbers: number[]`

## Salida

- `boolean` (`true` si hay duplicados, `false` si todos son unicos).

## Ejemplo

- Entrada: `[3, 1, 4, 3]` -> `true`
- Entrada: `[3, 1, 4, 2]` -> `false`

## Restricciones

- Resolver en una pasada principal.
- Justificar complejidad y estructura elegida.
