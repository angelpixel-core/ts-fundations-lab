# Analisis

## Complejidad

- Tiempo: O(n).
- Espacio: O(n) en el peor caso (todos unicos).

## Trampas comunes

- Ordenar primero para detectar duplicados (innecesario para este caso base).
- Usar loops anidados y caer en O(n^2).

## Traduccion academica

Se aplica estructura de hashing (set) para deteccion temprana de repetidos.
