# Ejercicio: First Non-Repeated Character

Dado un string, devolver el primer caracter que no se repite.

## Entrada

- `text: string`

## Salida

- `string | undefined` (si todos se repiten, devolver `undefined`).

## Ejemplo

Entrada: `"aabccdeff"`

Salida esperada: `"b"`

## Restricciones

- Resolver con enfoque de dos pasadas y tabla hash.
- Explicar complejidad temporal y espacial.
