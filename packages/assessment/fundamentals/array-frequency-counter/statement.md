# Ejercicio: Frequency Counter

Dado un arreglo de numeros enteros, devolver un objeto con la frecuencia de cada valor.

## Entrada

- `numbers: number[]`

## Salida

- `Record<number, number>` donde la clave es el numero y el valor es su cantidad.

## Ejemplo

Entrada: `[4, 1, 4, 2, 1, 4]`

Salida esperada: `{ 1: 2, 2: 1, 4: 3 }`

## Restricciones

- Resolver en una sola pasada principal.
- Explicar complejidad temporal y espacial.
