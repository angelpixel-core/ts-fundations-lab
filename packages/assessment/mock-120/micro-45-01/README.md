# Micro-simulacro 45 min - Sesion 01

Objetivo: entrenar lectura academica, seleccion de estructura y claridad de justificacion.

## Reglas

- Duracion total: 45 minutos con timer real.
- Sin ayuda externa.
- Resolver en este orden y registrar tiempos.

## Secuencia

### Bloque A (15 min) - Fundamentos

Ejercicio: `packages/assessment/fundamentals/first-non-repeated-char/statement.md`

Entrega minima:

- pseudocodigo breve
- solucion TS
- complejidad temporal/espacial

### Bloque B (15 min) - Estructuras

Ejercicio: `packages/assessment/fundamentals/stack-balanced-parentheses/statement.md`

Entrega minima:

- enfoque con stack
- solucion TS
- explicacion de por que contar simbolos no alcanza

### Bloque C (15 min) - Trampa conceptual

Ejercicio: `packages/assessment/traps/queue-efficiency-claim/statement.md`

Entrega minima:

- veredicto (verdadero/falso)
- justificacion en 3-5 lineas
- mencionar dependencia de implementacion

## Criterio de correccion (100 puntos)

- Correctitud tecnica: 40
- Complejidad y justificacion: 25
- Claridad academica del lenguaje: 20
- Manejo de trampas/absolutos: 15
