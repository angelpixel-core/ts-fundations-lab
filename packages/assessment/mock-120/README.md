# Mock 120

Simulacros de 120 minutos en modo examen.

## Protocolo

1. Timer real de 120 minutos.
2. Resolver sin ayuda externa.
3. Registrar errores por categoria:
   - lectura
   - complejidad
   - modelado POO
   - edge cases
4. Hacer post-mortem inmediato en un archivo de notas.

## Plantilla rapida de post-mortem

- Que falle
- Por que falle
- Como lo resolveria mejor en un segundo intento
- Regla academica para recordar
